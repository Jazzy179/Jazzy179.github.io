# 仲家傲 · AI 产品经理个人网站

这是可直接部署到 GitHub Pages 的个人数字名片。它与 PDF 作品集和 GitHub 主页分工不同：网站主要展示个人介绍、求职状态、最近动态、精选项目入口和经历。

## 本地预览

```bash
python3 -m http.server 4173
```

访问 `http://localhost:4173`。

## 发布到 GitHub Pages

1. 使用 GitHub 账号 `Jazzy179`，新建公开仓库 `Jazzy179.github.io`。
2. 将本目录全部文件推送到仓库的 `main` 分支。
3. 在仓库 Settings → Pages 中选择从 `main` 分支发布。
4. 发布后地址为 `https://jazzy179.github.io/`。

GitHub 主页为 `https://github.com/Jazzy179`；交互作品入口 `https://jazzy179.github.io/Jazzy179/` 保持独立。

## 对外口径

- 网站只展示少量公开口径，完整案例统一放在 PDF 作品集中。
- 所有内部数据使用约数或区间。
- “系统处理正常结束”不等于“用户任务完成”。
- 17 项 Bad Case 需求只写“形成建议”，不写成“已采纳或上线”。
- 界面为公开页面、用户提供的演示稿或脱敏交互原型。
